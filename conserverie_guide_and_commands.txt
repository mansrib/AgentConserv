================================================================================
دليل النشر على منصة Render.com (Publication sur Render)
مشروع: محل زينب العزيزي لتعليب المأكولات التونسية (بن عروس)
================================================================================

1. الملفات الجاهزة للنشر (حطهم الكل في نفس المجلد أو في GitHub Repository):
   - tunisian_packaging_bot.html     (الواجهة الكاملة بالأفاتار المحجبة والتسجيلات الصوتية الأربعة)
   - whatsapp_conserverie_server.py  (سيرفر البايثون المجهز لـ Render يفتح الموقع على الرابط الرئيسي /)
   - conserverie_database.json       (قاعدة البيانات بالأحجام 3500/2500/2000 والتوقيت والتوصيات)
   - requirements.txt                (مكتبات البايثون اللازمة لـ Render)

================================================================================
2. الإعدادات اللي تحطها في موقع Render.com (New -> Web Service):
================================================================================

- Runtime / Environment :  Python 3
- Build Command         :  pip install -r requirements.txt
- Start Command         :  python whatsapp_conserverie_server.py
- Instance Type         :  Free (أو Starter)

ملاحظة مهمة:
- السيرفر `whatsapp_conserverie_server.py` يقرأ أوتوماتيكياً متغير `PORT` الخاص بـ Render
  ويعرض صفحة `tunisian_packaging_bot.html` مباشرة عندما يفتح أي حريف رابط موقعك:
  https://www.google.com/search?q=https://your-app-name.onrender.com/

================================================================================
3. ربط الواتساب (Webhook) مع رابط Render الجديد:
================================================================================
بعد ما يكمل النشر على Render ويعطيك الرابط (مثلاً https://www.google.com/search?q=https://zaineb-conserverie.onrender.com):
- رابط الـ Webhook للواتساب (Green-API أو UltraMsg) هو:
  https://www.google.com/search?q=https://zaineb-conserverie.onrender.com/webhook/whatsapp
- رابط قاعدة البيانات:
  https://www.google.com/search?q=https://zaineb-conserverie.onrender.com/api/database

================================================================================
4. محتوى ملف render.yaml (اختياري للنشر التلقائي عبر Blueprint):
================================================================================
services:
  - type: web
    name: zaineb-conserverie-tunisie
    runtime: python
    plan: free
    buildCommand: pip install -r requirements.txt
    startCommand: python whatsapp_conserverie_server.py
    envVars:
      - key: PYTHON_VERSION
        value: 3.11.0
================================================================================
